# SuzuMail

自建邮件服务器项目：用自有域名收发邮件（如 `admin@suzu.life`）。

## 架构定案（2026-11-24）

- **核心**：[Stalwart](https://github.com/stalwartlabs/stalwart)（开源，AGPL-3.0 社区版）**原版部署、不深改 fork**——邮件协议坑深、安全更新频繁，跟上游走；我们只写外层。
- **宿主**：Vultr 东京（IP 池相对干净、25 端口可工单解封、PTR 可自设）。开机先验 IP 黑名单，脏了删机重开换 IP。
- **我们自研的外层**（本仓库的内容）：
  - 部署脚本（Docker 一键起 Stalwart）
  - DNS 自动化：经 Cloudflare API 一键配齐 SPF / DKIM / DMARC / PTR
  - 备份脚本
  - 黑名单巡检：IP 被任何名单收录立即报警（接入日常巡检）
- **发信策略**：先直发 + 养 IP（头两周小量慢发）；送达率不达标时切换混合模式——发信走 Brevo / SES 中继，收信与邮箱本体仍在自己服务器。
- **与全家桶的关系**：只在全家桶首页（suzu.party 门户）挂一个链接展示，**用户信息完全不同步、不打通账号**，邮箱是独立一套账号体系。

## 域名

- 服务域名（计划）：`mail.suzu.life`
- 邮箱域名：`suzu.life`（如 `admin@suzu.life`）
